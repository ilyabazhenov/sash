Терминал, клавиши и голос: всё, чем вы отвечаете агентуThe terminal, the keys and your voice: all you answer an agent with

Sash ничего не меняет в Claude Code: он показывает экран Mac и передаёт на Mac ваш ввод. Поэтому так же работают Codex CLI, Gemini CLI, Aider и любой агент в терминале или редакторе.Sash changes nothing in Claude Code: it shows the Mac’s screen and passes your input to the Mac. So Codex CLI, Gemini CLI, Aider and any agent in a terminal or an editor work the same way.

Чем это отличается от Remote Control в Claude Code?How is it different from Claude Code’s Remote Control?

Remote Control переносит в приложение Claude разговор с агентом. Sash показывает весь Mac: тот же терминал, а рядом браузер, симулятор, редактор и другие агенты. Одно другому не мешает, ими можно пользоваться вместе.Remote Control brings your conversation with the agent into the Claude app. Sash shows the whole Mac: the same terminal, and next to it the browser, the simulator, your editor and other agents. They don’t get in each other’s way; you can use both.

Нужно ли что-то настраивать в Claude Code?Do I need to set anything up in Claude Code?

Нет. Sash не трогает Claude Code и его настройки: он показывает экран Mac и передаёт ввод, как будто вы сидите за клавиатурой.No. Sash doesn’t touch Claude Code or its settings: it shows the Mac’s screen and passes your input on, as if you were at the keyboard.

Агент остановится, если телефон отключится?Does the agent stop if my phone disconnects?

Нет. Агент работает на Mac, а Sash только показывает его окно. Обрыв связи, погашенный экран или закрытое приложение на телефоне на агента не влияют: откроете Sash снова — и увидите, что он успел.No. The agent runs on the Mac; Sash only shows its window. A dropped connection, a dark screen or a closed app on the phone don’t affect the agent: open Sash again and see what it has done.

Сообщит ли Sash, что агент ждёт ответа?Will Sash tell me when the agent is waiting?

Пока нет: загляните в окно терминала в Sash. Уведомлений от Mac в приложении ещё нет.Not yet: look at the terminal window in Sash. The app doesn’t get notifications from the Mac yet.

Работают ли другие агенты?Do other agents work?

Да. Sash всё равно, что запущено на Mac: Codex CLI, Gemini CLI, Aider, агент в Cursor или Xcode — любое окно видно и управляется так же.Yes. Sash doesn’t care what runs on the Mac: Codex CLI, Gemini CLI, Aider, the agent in Cursor or Xcode — any window shows and is driven the same way.

Есть ли версия для iPhone?Is there a version for iPhone?

Скоро: Sash для iPhone и iPad готовится к выходу в App Store. Пока доступна версия для Android.Soon: Sash for iPhone and iPad is on its way to the App Store. For now, the Android version is available.
