- **Вне дома через relay Sash.** Сопряжённый телефон теперь достаёт до своего Mac через мобильный интернет без Tailscale и проброса портов. На Mac откройте «Настройки» › «Удалённый доступ» и включите «Удалённый доступ» и «Подключаться через relay Sash». Телефон идёт через relay, когда ничего ближе не отвечает.
- **Заблокированный Mac показывает только экран блокировки.** Пока Mac заблокирован, устройства не получают ни окон, ни миниатюр, ни меню, ни буфера обмена, а Sash для Android пишет «Mac заблокирован». Введите пароль с телефона, и после разблокировки вернётся окно, которое вы смотрели.
- **Sash для Mac на русском** — на языке системы.
- **Картинка возвращается после сна дисплея.** Если дисплей Mac уснул посреди трансляции, картинка теперь сама вернётся, когда он проснётся.
- **Sash для Android отпускает Mac через 3 минуты в фоне.** Телефон, оставленный подключённым, больше не держит сеанс Mac. Когда вы вернётесь в Sash, он переподключится и попросит то, что транслировалось.
- Ссылки и QR-коды для сопряжения теперь `sash://pair`, а оба приложения везде называют приложение для Mac Sash.
- Исправления по итогам проверки безопасности Sash для Mac.

**Обновите оба приложения.** Sash для Android 1.10 не читает QR-коды сопряжения Sash для Mac 1.11. Уже сопряжённые устройства продолжают работать.
